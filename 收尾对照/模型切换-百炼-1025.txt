二、你要做的一件事：填密钥
============================================================
三种方式，优先级从高到低，任选一种即可：

  ① 环境变量  DASHSCOPE_API_KEY            （最干净，不落文件）
  ② 文件      agent\llm_key.txt            （一行，只放 key；已进 .gitignore）
  ③ 源码      agent\llm_config.py 里 API_KEY = "sk-..."

推荐 ②：新建 agent\llm_key.txt，把 key 粘进去、保存即可，不会被传到 GitHub。
注意 API_KEY 常量现在是空的——别把百炼的 key 填到会提交的文件里。

三、填完先自检（30 秒，不启服务也能跑）
============================================================
  cd 研一项目
  python agent\llm_config.py

  → 成功：  回答：可用 / 耗时：x.xx 秒 / 用量：{...}
  → 没填：  "还没填密钥：打开 agent/llm_config.py ..."
  → 401：   密钥不对（别拿 DeepSeek 官方那把 key，两个平台不通用）
  → 404：   地址或模型名不对 → 去百炼控制台「模型广场」复制准确模型名
  → 403：   这个模型没开通 / 欠费（学生券看下是否绑到该模型）

五、几个设计取舍（为什么这么写）
============================================================
1. chat() 返回 (text, usage, cost, err)，err 是一句人话，不再让调用点自己判断状态码。
   五个调用点的函数签名（ask_model 等）保持不变，上层代码一行都没动。

2. 参数降级：百炼不认某些可选参数时（400/422），自动去掉
   response_format / temperature / max_tokens / thinking 只发 model+messages 重试一次，
   并打印一行提示。JSON 输出靠 prompt + parse_json_reply 的宽容解析兜底，不会因此中断。

3. 关思考开关没写死：THINKING_OFF_STYLE = "enable_thinking"（实测最优，见第七节）。
   这个模型默认会"边想边答"，解析一句指令多花 2~3 秒；关掉后 1.8s 左右，结果质量不变。
   换别的模型若不认这个字段，会自动降级去掉重试，不会把功能搞挂。

4. MODEL / BASE_URL 支持环境变量覆盖（A23_MODEL / A23_LLM_BASE_URL），
   想临时对比两个模型不用改代码。

5. 连接复用保持原样：parse_intent 继续传自己的线程本地 Session（省 0.2~0.4s 握手）；
   其他调用点用 llm_config 内部的线程本地 Session。
