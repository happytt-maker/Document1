# 准确率口径规范 v1

> 写这份东西的唯一目的：**把"填得对不对"这件事从口头判断变成可复算的规则**。
>
> 以前的问题不是算错了，而是只有模板 4 有逐格答案，另外 4 张表"验收通过"只代表
> 结构没写歪，不代表值填对了。所以那个 85.7% / 100% 其实只是**一张表**的成绩，
> 不是五张表的成绩 —— 拿它当"系统准确率"是不成立的。
>
> 这份规范配 `评分器.py`，规则和代码一一对应，任何人拿同一份答案跑，出的分必须一样。

---

## 1. 评什么：三个维度，不要混着算

| 维度 | 回答的问题 | 谁在乎 |
|---|---|---|
| **结构** | 表头认出来了没？待填区圈对了没？ | 我们自己（结构错，后面全错） |
| **值** | 该填的格子填对了吗？ | 赛题（准确率就指这个） |
| **出处** | 每个值能不能指回源文档某一行？ | 作品要求（可追溯） |

赛题原文只说"填写后的表格与样例表格进行对比，计算出准确率"，指的就是**值**。
所以对外报的准确率一律是**值**的准确率；结构和出处单独报，不混进去充数。

---

## 2. 判定前先归一化（两档都做）

两个值的比较，先各自过一遍下面这套变换，再做判定。这一步不算"放水"，
因为 `1,200` 和 `1200` 本来就是一回事，不归一化才是错的。

| # | 规则 | 例子 |
|---|---|---|
| N1 | 去首尾空白，连续空白压成一个 | `" 张三 "` → `"张三"` |
| N2 | 全角转半角（数字/字母/括号/逗号/冒号/分号） | `"１２００"` → `"1200"`，`"（元）"` → `"(元)"` |
| N3 | 中英文标点统一成中文全角 | `"1,200.00"` → `"1200.00"`（见 N4） |
| N4 | 去掉数字千分位逗号 | `"1,200.00"` → `"1200.00"` |
| N5 | 去掉包裹的引号/书名号 | `"「已验收」"` → `"已验收"` |
| N6 | 英文转小写 | `"VMC-850B"` vs `"vmc-850b"` 视为相同 |

**不做**的事（做了就是作弊）：
- 不删单位。`"12 台"` 和 `"12"` 不是一回事，单位是信息。
- 不做近义词替换。`"已验收"` 和 `"验收完成"` 不是同一串字符。
- 不截断长文本。"客户确认满意"和"客户确认满意，已回访"长度不同，内容不同。

---

## 3. 严格档：字符串完全一致

归一化之后，两个值**逐字符相等**即为命中。

用途：这是**下界**。严格档的分，是"换任何评委来都挑不出毛病"的分。
对外报成绩时，先说这个数。

---

## 4. 宽松档：承认格式差异

在严格档之外，满足下面任一条也算命中。用途：这是**上界**，
代表"人看一眼会说'这填的是对的，只是写法不一样'"。

| # | 规则 | 例子 | 为什么放行 |
|---|---|---|---|
| L1 | 数值等价（转 float 比较，容差 1e-6） | `"1200"` / `"1200.00"` / `"1,200"` | 同一个数 |
| L2 | 数值区间（一方含另一方且是同一数） | `"1200元"` / `"1200"` | 只在**该列单位已写在列名里**时放行（如列名"单价(元)"） |
| L3 | 日期等价（解析成 y/m/d 比较） | `"2026年1月19日"` / `"2026-01-19"` / `"2026/1/19"` | 同一天 |
| L4 | 布尔/状态等价 | `"是"`/`"Y"`/`"√"`；`"否"`/`"N"`/`"×"` | 同一状态 |
| L5 | 一方包含另一方，且短的一方 ≥4 字 | `"无锡恒信精密制造有限公司"` 含 `"无锡恒信"` | 简称与全称 |
| L6 | 编辑距离 ≤ 较长串长度的 10%（且长度≥6） | 错一个字的公司名 | 允许手误，不放行整句不同 |

**L1/L2 的边界**：只有当列名本身含单位（`(元)`/`(天)`/`(台)`）时，才允许
值里带不带单位都算对。列名没单位而值多了单位，严格档不命中，宽松档按 L2 放行
但会在明细里标 `单位差异`，方便你判断是不是列理解错了。

**L6 是唯一的"模糊"规则，要警惕**：它可能把"金额填错一位"救回来。
所以宽松档命中里凡是靠 L6 的，明细一律标 `近似`，单独统计条数。
如果 `近似` 条数超过总格的 5%，这个宽松分就不能信。

---

## 5. 留空与错填：错填比漏填更严重

一张表里不是所有格子都该填。源文档只有 3 条记录，模板有 6 行空白区，
后 3 行**必须留空**。这时候：

| 情况 | 记法 | 理由 |
|---|---|---|
| 应填 → 填对 | 命中 | 正分 |
| 应填 → 填错 | 未命中 | 0 分 |
| 应填 → 留空 | 漏填 | 0 分，明细标 `漏填` |
| 应留空 → 留空 | 正确留空 | 正分 |
| 应留空 → 填了东西 | **错填** | 0 分，明细标 `错填`，**单独统计** |

错填单列出来，是因为它对下游伤害最大：留空至少人一眼看得出"这里没查到"，
错填会被人当真值用下去。所以报告里错填条数必须单独给，不能藏在总数里。

---

## 6. 准确率怎么算

```
整体准确率（对外报的就是这个）
  = (严格命中格数 + 正确留空格数) / 表格总格数
  其中 表格总格数 = 应填格数 + 应留空格数

应填格准确率（诊断用）
  = 严格命中格数 / 应填格数
```

同时输出宽松档的两个数。**最终对外只报一个区间**：

> 严格 X%（下界）～ 宽松 Y%（上界），其中靠"近似"规则命中的 N 格

不取平均、不取"宽严中间值"—— 中间值没有定义，取了就是编。

---

## 7. 和赛题怎么对齐

赛题原文（第 87 行）：

> 每次填写表格的准确率至少为 80%，每个文档的响应时间至多为 90 秒。
> 当 5 个表格均填写完成后，计算平均准确率和平均响应时间。

所以对外要给的，是**每张表一个准确率 + 一个平均准确率**，加**每文档一个耗时 + 平均耗时**。
单张表不达 80% 就是硬伤，不能靠平均分掩盖。报告里对每张表单独标 `达标/未达标`。

赛题没说"准确率"是严格还是宽松口径。这是**已知的不确定性**，
不能假装解决了 —— 所以两个数都给，并说明差异来源。这一点会写进参赛材料的
"评价方法对齐"一节，如实标注为假设。

---

## 8. 这套口径管不到的地方

说清楚边界，比说得漂亮重要：

1. **答案本身是我按源文档整理的**，不是比赛方给的。所以它衡量的是
   "系统与我的理解是否一致"，不等于"系统与比赛方样例是否一致"。
   缓解办法：每份答案标 `复核状态`，未经人工复核的答案，其分数要打折看待。
2. **单元格只有一个值**。源文档一条记录有多个值时（如多个联系电话），
   约定用 `；` 连接，顺序不影响判定（该列会按集合比较）。
3. **不谈语义正确性**。摘要类字段（如"投诉内容摘要"）原文概括得对不对，
   字符匹配判不了。这类列标 `主观列`，只判"非空且能溯源"，不计入值准确率，
   并在报告里单独列出，由人看。
4. **不做跨表一致性校验**。两张表里同一个客户名写法不同，本规范不管。

---

## 9. 怎么跑

```
python 收尾对照/评测/评分器.py                    # 全部表
python 收尾对照/评测/评分器.py --table 模板1       # 单表
python 收尾对照/评测/评分器.py --verbose           # 逐格明细
```

输入：
- 标准答案：`收尾对照/评测/标准答案/*.json`
- 已填写：`五表连测/结果-模板N/模板N-XXX-已填写.xlsx`

输出：`收尾对照/评测/评分报告.txt`（同时打印到屏幕）
