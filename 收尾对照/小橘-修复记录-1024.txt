A-23 客服 / 数字人「小橘」三项问题修复记录 · 2026-10-24
服务：http://127.0.0.1:8000　文件：agent/web/index.html

==================== 一、发一条消息显示两条 ====================
现象：AI 会话里只发了一句，对话框里同一条出现两遍。
根因：本地为了手感先插一条用户气泡（没有 id），而 AI 回复要等大模型 1~2 秒；
      1.6 秒轮询先用旧 lastId 把这条用户消息从服务端拉了回来，前端不认识它，又插一遍。
      ——不是后端重复写库，纯粹是前端的「乐观上屏」和「轮询」互相不认识。

改法（index.html）
1. csState 增 seen（已上屏的消息 id 集合）、pending（本地已上屏、还没拿到 id 的用户消息）。
2. csSendMsg：本地那条改成带 data-pending 的 DOM，并登记进 pending。
3. csAddMsg：遇到 sender=user 且能和 pending 对上内容时，只把回执的 id「认领」给它、
      写进 seen、刷新 lastId，然后 return false（不新增节点）。
      发送响应里的 j.message 也走同一条路，保证幂等。
4. 发送失败：撤掉本地那条、原文放回输入框。
5. csRenderSession：切会话时 seen/pending 一起重置。

==================== 二、说话时嘴跳来跳去 ====================
现象：小橘念答案时嘴快速抽动，不像说话。
根因两条，叠在一起：
  a) 口型值 = 两条高频正弦（10.5 / 4.3 rad/s）直接相加，每帧 0.16~1.0 硬切，
     没有平滑，频率也不像音节；
  b) CSS 里嘴巴是 .dh-mouth 元素自身的 scaleY，且没有 transform-origin，
     缩放围绕自身中心 → 上下同时撑开，看起来是「弹」不是「张嘴」。

改法
1. dhMouthLoop 重写：3.1 Hz 音节包络 + 1.3 Hz 语调起伏，pow 1.7 压出闭合对比，
   幅度收到 0.04~0.62；每帧按真实 dt 做指数平滑（张口快、闭口慢）。
2. .dh-mouth 改 transform-box: fill-box; transform-origin: 50% 0%，
   并改成 <g class="dh-mouth"> 包住口腔和舌头，从上颚往下张。
3. 说话幅度 scaleY(calc(.55 + mouth * 1.55))，张嘴看得见但不夸张。
4. 顺带修：说话时眼睛 scaleY(.82) 压成一条缝 → 改 .95；眨眼闭合区间 92~95% → 93~96%。

==================== 三、小橘要更像真猫 ====================
改法（全部手写 SVG，无外部图片、断网可用）
1. 眼睛：纯黑圆豆 → 杏仁形 + 黄绿径向渐变虹膜 + 竖瞳（rx3.2/ry8.2）+ 双高光 + 上眼睑阴影。
2. 口鼻：两瓣白色唇垫 + 心形粉鼻（带高光）+ 人中线 + W 形嘴。
3. 耳朵：尖细狐狸耳 → 宽底圆尖猫耳，粉内耳 + 耳毛。
4. 毛色：橘色三段渐变、额头 M 纹、脸颊条纹、下巴投影、右侧背光。
5. 身体：梨形坐姿，胸口白毛从下巴铺到肚子，两条竖向阴影暗示前腿，前爪带趾缝。
6. 尾巴：加环纹（stroke-dasharray 叠深色）+ 高光。
7. 六根胡须，外浅内深。

顺带修掉一个隐藏 bug：眼睛的定位写在 <g class="dh-eye" transform="translate(77 106)">，
而状态样式又给它 CSS transform，CSS 会覆盖属性 transform → listen/think/speak 三种状态下
眼睛会跑出脸外。改成外层 g 定位、内层 .dh-eye 只做状态缩放。
