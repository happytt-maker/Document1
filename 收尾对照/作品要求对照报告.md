## 三、首查暴露的 5 个缺口 & 补齐动作（本轮核心）

| 缺口 | 问题本质 | 补齐动作 | 落点文件 |
|---|---|---|---|
| **A3** 识别/填写没有操作台入口 | 能力在命令行有，但网页上"看不见、点不到" —— 不满足"合理引导、即触即用" | 顶栏新增「🧠 识别入库」「📋 表格填写」两按钮 + 两个弹窗面板 + 操作指南补 2 条 | `agent/web/index.html` |
| **A4 / B6** 识别分类没有**专属** API、异步范式没挂到识别上 | 异步机制此前只挂在"自然语言指令"上；赛题点名的"识别分类模块"没有自己的接口 | 新增 `POST /api/recognize`（支持 profile / entities / fields 三线，11 个中文别名）+ `Job.kind` 区分任务类型 | `agent/api_server.py` |
| **A8** 表格填写没有 API / 图形入口 | "智能信息整合"只有脚本链路，没有服务入口 | 新增 `POST /api/fill`（异步）+ `GET /api/fill/templates`（10 张清单）+ `GET /api/fill/download`（产物下载）+ 操作台面板 | `agent/api_server.py` + `web/index.html` |
| **B5** 标注审核缺"说明"档案 | 有标准答案有复核记录，但缺一份讲清"怎么标、怎么审"的说明 | 新建《样本标注与审核说明.md》：样本总清单 / 标注口径 / 6 轮审核时间线 / 结果快照 | `收尾对照/样本标注与审核说明.md` |

**补强工程细节**：
- 识别任务跑完自动附**库内分布快照**（各表条数），填写任务报告正则抓取"写入 / 值一致 / 格式差异 / 结论 / 交卷文件"五要素；
- 填写用 `fill_lock` **全局串行**（同机防并发写冲突）；识别任务经统一执行入口 `run_edit` 复用模块2 三线，不复制代码；
- 验收中发现并修复一个真问题：识别请求缺字段名时校验顺序错误（先报 404 再报 400）→ 修正为字段线必须显式带字段名才启用。
