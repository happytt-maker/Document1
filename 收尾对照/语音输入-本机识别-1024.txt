语音输入「语音服务连不上」问题 —— 修复记录
日期：2026-10-24
环境：Windows 11 + Edge/Chrome + Python 3.13(managed venv) + FastAPI 127.0.0.1:8000

======================================================================
一、现象
======================================================================
网页操作台点「🎤 语音输入」，等几秒后提示：
  「语音服务连不上。Chrome 的识别要访问谷歌服务器，国内通常不通——请改用 Edge 打开本页」
换成 Edge 也一样，等于两条路都堵着。

======================================================================
二、根因（两层，都要治）
======================================================================
1) 浏览器自带的 SpeechRecognition 不是本地识别：麦克风音频要送到
   谷歌（Chrome）或微软（Edge）的语音服务器去转文字。国内网络下这条链路
   经常走不通，浏览器只会回一个 error.code = "network"。
2) 这台机器上还挂着本地代理（HTTP_PROXY=http://127.0.0.1:50721，
   系统代理 127.0.0.1:7897）。实测该代理对外返回 502 Bad Gateway，
   等于把原本就脆弱的语音链路又掐了一次。这也解释了为什么"换 Edge"没用。

结论：光换浏览器治不了，必须有一条**完全不出网**的识别通道。

======================================================================
三、方案：双通道 + 自动降级
======================================================================
通道①（保留）：浏览器原生识别 —— 实时出字、快，网络通的时候最好用。
通道②（新增）：本机录音 → 后端离线转写 —— faster-whisper 在 CPU 上跑，
               音频不出本机，断网也能用。

流程：
  第一次点按 → 走通道①
  一旦报 network → 立刻写 localStorage 标记（a23_asr_local=1），
                    自动切到通道②，提示"已切到本机离线识别——请再说一遍"
  之后这台机器每次都直接走通道②，不再白等那几秒

交互细节：
  · 点一下开始录音，再点一下结束；说完静音 1.4 秒也会自动结束（最长 40 秒）
  · 「取消」丢弃录音，不动输入框里已经打的字
  · 识别结果接在原有文字后面，不是覆盖
  · 识别完顺手弹一次"语音转文字准不准？"的评价

六、踩过的坑（下次别再踩）
======================================================================
1. pip 装包全部失败：HTTP_PROXY 指向的本地代理回 502。
   直连 pypi 超时、走代理 502。最终解法：清空代理环境变量后直连清华镜像，
   先抓 whl 到本地目录，再 pip install --no-index --find-links=该目录。
   注意：选包时要排除 rc/a/b/dev 预发布版，以及 cp313t（free-threaded）wheel。
   另：tokenizers 0.20 要求 huggingface-hub<1.0，默认会抓到 2.3 冲突，要降到 0.35.x。

2. ModelScope 直链 HEAD 返回 200 但没有 Content-Length，
   下载时要按 API 给的文件大小校验，别指望响应头。

3. MediaRecorder 停止顺序：必须先 mr.stop()，等 onstop 把最后一段数据
   吐出来，再关麦克风轨道。反过来会拿到 0 字节 blob，前端就报"没录到声音"。

4. 浏览器 headless 验收：没有真麦克风时用
   --use-fake-device-for-media-stream + --use-file-for-fake-audio-capture=<wav>，
   可以播一段真语音走完整链路；纯 fake-device（440Hz 正弦）只能测状态机。

5. FastAPI 的 File(...) 只吃 multipart/form-data，裸 body 会 422
   （"Field required: file"），验收脚本要手工拼 multipart。

6. 沙箱不允许 shutil.rmtree 几百个文件（SAFE_DELETE_BULK_CONFIRM_REQUIRED），
   验收脚本别删浏览器 profile，直接每跑一次换个新目录。

七、回滚
======================================================================
  代码：把 web\index.html.bak-asr 覆盖回 index.html，api_server.py 去掉 asr 相关
  模型：删掉 agent\models\faster-whisper-small 即可（不影响服务启动，
