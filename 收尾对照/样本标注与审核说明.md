## 二、标注方法（人工怎么标）

1. **人工通读源文档，圈定"应有什么"** —— 以人读为准，不以程序输出为准（防止"程序抽到啥就算啥"的自我循环）。
2. **多形态可接受列表**：每个应含值给出全部合法形态（如金额 `1,800,000` / `￥1,800,000.00` / `壹佰捌拾万元`），任选其一命中即算对——不因表述差异误判。
3. **模板4 对分由人先答**：全部 21 格由人工完成（含"先看哪、怎么找、哪里犹豫"的过程记录），存档留痕；程序产物与人工作答分开对分。
4. **压测金丝雀人工设计**：15 组受保护埋点分三形态（标签段 / 小表格 / 深处记录）、三组别（A1 必达 / A2·A3 次验 / B 观察）；生成时与高频词库全局去重（`PROTECTED` 集合），保证值唯一可查。
