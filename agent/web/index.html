它支持这些文档和操作

📄Word 文档.docx
加粗斜体下划线删除线高亮颜色字体字号 居中 / 左 / 右 / 两端对齐行距首行缩进 改字删字加字字段提取自动抽取知识
全功能：文字格式 + 段落版式 + 编辑 + 读取信息
📊Excel 表格.xlsx
加粗斜体下划线删除线底色高亮颜色字体字号对齐 改字删字字段提取自动抽取知识
可用「表头 / 某列 / 某个词」精确定位要动的格子
📝Markdown 与纯文本.md / .txt
加粗斜体删除线高亮标红 改字删字加字字段提取自动抽取知识
纯文本没有「居中 / 行距」这类版式写法，会明确提示
🤖 不想打字？点左边「智能操作」：上面一排小按钮（加粗 / 斜体 / 下划线 / 高亮 / 居中 / 行距…）点一下就生效， 下面点一份文件即可；也能什么都不选，直接在底下的框里说 设备采购合同的标题加粗
✨ 一句话可含多个操作：标题右对齐，并且加粗 一次做两步、结果在同一份文件里
🧭 想快速看懂一份文档？说 自动读懂XX并提取关键信息 —— 系统先认出这份文档自己的对象和属性（合同是合同、报告是检验项目，不套固定分类），再逐条抽值，条条带出处
🗄 抽出来的东西全进数据库：对象 / 属性 / 关系 / 事件 / 要点，点顶栏「数据仓库」一个视图看全，可按类型筛、按关键词搜；同一窗上半部分就是📚 文档库—— 能上传、看清单、对单份文档一键「🧠 提取入库」
📥 新文档随时导入：点输入框左边的「导入文档」上传 docx / xlsx / md / txt，或者打开「🗄 数据仓库 → 📚 文档库」直接传（那里还支持 PDF / 图片，扫描件自动 OCR）—— 自动识别格式，解析完立即可用
🖼 图片也能插进文档：把图片直接拖进对话框就选中了（png / jpg / gif / bmp / webp），再说一句 插到标题下面 或 放到文末 —— 自动找位置、居中、按页宽缩放，原格式不动
🗄 提取的数据全进数据库：实体 / 画像 / 字段提取完成即自动入库，点顶栏「数据仓库」随时查、按类型筛、搜关键词；同一窗上半部分就是📚 文档库—— 能上传、看清单、对单份文档一键「🧠 提取入库」
🔍 数据质量随手体检：数据仓库里点「质量体检」 —— 把库里的数据拿回原文核对（保真度）+ 对照人工标准答案算查全率，秒级出结果
🧠 让系统自己盘文档：点顶栏「识别入库」—— 勾文档（可加一句关注点），提交后后台自动读懂结构、抽值、入库（也可以直接说「自动读懂XX」）
📋 把数据填进表格：点顶栏「表格填写」—— 选模板 + 勾源文档（数据从哪几份里找）+ 写要求，一键跑「读懂 → 找数 → 填写 → 自检」，完成后直接下载已填写表格
