纯文本没有「居中 / 行距」这类版式写法，会明确提示
✨ 一句话可含多个操作：标题右对齐，并且加粗 一次做两步、结果在同一份文件里
🧭 想快速看懂一份文档？说 提取XX的关键信息 —— 出一份画像：主题 + 核心要点 + 关键要素，条条带原文出处
🏷️ 想把文档里的"料"盘出来？说 识别XX里的实体数据 —— 人名 / 机构 / 日期 / 金额 / 编号 / 联系方式 / 产品设备 7 类分类成表，条条带出处
📥 新文档随时导入：点输入框左边的「导入文档」上传 docx / xlsx / md / txt，自动识别格式、解析完成后立即可用
🖼 图片也能插进文档：把图片直接拖进对话框就选中了（png / jpg / gif / bmp / webp），再说一句 插到标题下面 或 放到文末 —— 自动找位置、居中、按页宽缩放，原格式不动
🗄 提取的数据全进数据库：实体 / 画像 / 字段提取完成即自动入库，点顶栏「数据仓库」随时查、按类型筛、搜关键词
🔍 数据质量随手体检：数据仓库里点「质量体检」 —— 把库里的数据拿回原文核对（保真度）+ 对照人工标准答案算查全率，秒级出结果
🧠 让系统自己盘文档：点顶栏「识别入库」—— 勾文档、选识别线（画像 / 实体 / 指定字段），提交后后台异步识别、自动入库（也可以直接说「识别XX里的实体数据」）
📋 把数据填进表格：点顶栏「表格填写」—— 挑一张模板一键跑「读懂 → 找数 → 填写 → 自检」，完成后直接下载已填写表格
